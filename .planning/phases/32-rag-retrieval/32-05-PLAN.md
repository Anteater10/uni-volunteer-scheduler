  <name>Task 2: Implement GET /api/v1/copilot/citations/{chunk_id} (GREEN)</name>
  <files>backend/app/copilot/router.py</files>
  <action>
    Add to the existing copilot router:
    ```python
    @router.get("/citations/{chunk_id}", response_model=CitationDetail)
    def get_citation(
        chunk_id: UUID,
        db: Session = Depends(get_db),
        _user = Depends(_require_admin_or_organizer),
    ) -> CitationDetail:
        row = db.execute(
            text("""
              SELECT cc.char_start, cc.char_end, cc.content, cd.source_path
              FROM corpus_chunks cc
              JOIN corpus_documents cd ON cd.id = cc.document_id
              WHERE cc.id = :id
            """),
            {"id": chunk_id},
        ).one_or_none()
        if row is None:
            raise HTTPException(404, "Citation not found")
        origin = settings.corpus_source_origin_url.rstrip("/")
        doc_url = ""
        if origin:
            doc_url = f"{origin}/{row.source_path.lstrip('/')}"
        return CitationDetail(
            source_path=row.source_path,
            char_start=row.char_start,
            char_end=row.char_end,
            content=row.content,
            document_url=doc_url,
        )
    ```

    Constraints:
    - Use `UUID` type annotation so invalid UUIDs 422 at FastAPI parse time (eliminates path-traversal risk; RESEARCH §V5).
    - Same auth guard as Plan 04 (admin/organizer).
    - Per-provider filter NOT needed here (citation lookup is by chunk id, not retrieval).
  </action>
