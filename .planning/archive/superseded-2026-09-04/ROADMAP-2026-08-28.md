## W-QR — Signup QR generator · **spec settled 2026-08-28** · est. 0.5 day

**What Andy asked for.** On the admin event page (`Admin / <Event>`), alongside
the existing **Check-in QR** button, add a **Signup QR** button that generates a
QR code pointing at that event's **public volunteer signup page**:

```
{base}/volunteer/events/{eventId}
e.g. https://scitrek-preview.onrender.com/volunteer/events/b00954b2-c2e5-4812-9e0e-bb6a748f3422
```

**This is a second, distinct QR — not a change to the existing one.**

| | Check-in QR (exists) | **Signup QR (new)** |
|---|---|---|
| Target | `/event-check-in/{id}?v={venueCode}` | `/volunteer/events/{id}` |
| Audience | volunteers already signed up, at the door | anyone, before the event |
| Gating | venue code (a credential) | none — public page |
| Safe on paper//flyers? | no | **yes** |

**Why it's the smaller half-day.** Everything needed already exists:
`qrcode.react` ^4.2.0 is installed, `CheckInQRModal.jsx` is a working template,
and `resolveBaseUrl()` + the localhost warning at `CheckInQRModal.jsx:7-16` are
directly reusable. The new modal is simpler — no roster fetch, no venue code, so
no async state at all. The URL is derivable from `eventId` alone.

**The one real trap: event visibility.** `backend/app/routers/public/events.py:79`
returns the event only when `visibility == "public"`. A QR generated for a
private or draft event scans to a 404 for every volunteer, and nobody finds out
until they are standing in a hallway. **Disable the button (or show an inline
warning) when the event is not public** — this is the requirement most likely to
be skipped and the only one that fails in the field.

**Smaller calls, defaults chosen — say the word to change any:**

- **Screen + download.** Render on screen like the check-in modal, plus a
  "Download PNG" button. `QRCodeCanvas` (not `QRCodeSVG`) makes this a
  `toDataURL()` one-liner; SVG would need a serialize-and-rasterize step.
- **Show the URL as copyable text** under the code — email and Slack beat paper
  for a signup link, and it makes the modal useful without a printer.
- **Include the event title** above the code, matching the check-in modal, so a
  printed sheet identifies itself.
- **Error correction level M** and a quiet zone — a UUID URL at level H gets
  visually dense enough to hurt scan rates on a phone camera.

**Unblocked.** No longer waits on any decision. Still build it **before Phase 7**
so W6 actually clicks through it.
