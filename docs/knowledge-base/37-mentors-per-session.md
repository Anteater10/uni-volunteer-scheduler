# How many mentors a session needs, and what "understaffed" means

**A module session running with fewer than 6 mentors is considered understaffed.** Six is the
threshold SciTrek staff use when deciding whether a session needs more volunteers, so a session
sitting at 5 or fewer signups is the one to chase. **It is a program convention held by staff, not a
number stored anywhere in the app** — nothing in the software knows about six, so you will not find a
badge, warning, or report built around it.

"Understaffed" is therefore a staffing judgement rather than a status the app enforces. Nothing blocks
a session from running below 6, and the app will not refuse signups or cancellations to protect the
threshold. Slot capacity is a separate, unrelated number: capacity is the maximum a slot will accept
before new signups go to the waitlist, whereas 6 is the minimum staff want to see actually attending.

**Operations will not tell you which sessions are thin.** It lists events — title, date, location —
with no signup or capacity figures at all. To judge staffing you have to open the event itself.

**The per-session headcount lives on the roster.** Each session's header there reads as a check-in
figure — "2 / 7 checked in" — and the second number is the count that matters for staffing: the
volunteers that session actually expects, with waitlisted and cancelled signups excluded. That is the
number to compare against six, and it is readable well before the day.

**The event detail page gives the event-level picture**, and any staff member can open it: total slot
capacity alongside confirmed and waitlisted counts, plus every volunteer listed under their session
with a status. Be careful with its per-session "signed up" count, though — that one includes
waitlisted and cancelled people, so it reads higher than the number of mentors you'll get. Count the
statuses, or use the roster.

**Admins get two shortcuts organizers don't.** The admin Overview page has a **Needs attention**
panel listing upcoming events for the next couple of weeks with a filled-against-capacity badge,
flagged red when an event is nearly empty with under three days to go. And the **Event fill rate**
report under Admin → Exports gives capacity, seats filled, and percentage per event across a date
range, which is the quarter-wide view. Both of those pages are admin-only, so an organizer chasing
staffing either works event by event or asks an admin to pull the report.

The usual fixes for an understaffed session are promoting people off the waitlist, or sending a
broadcast to ask for more volunteers. **Promoting is no longer an instant headcount gain** — a
promoted volunteer is emailed a link and has three days to confirm the spot, so if you are counting
mentors for a session tomorrow, count who has actually confirmed.
